# Security and Responsible Disclosure

This is a **public case study only**; no executable broker integration or production Telegram configuration is published.

Do not open pull requests containing account/session cookies, passwords, Telegram bot keys, private chat IDs, broker proprietary payloads, encrypted token files, production ledgers, client images or messages, or confidential engineering source.

If an accidental leak is found, report the affected file/location without reposting the secret and request private removal and credential rotation where necessary.
